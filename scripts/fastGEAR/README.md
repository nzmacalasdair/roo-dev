This is a collection of scripts to simplify the process of running fastGEAR on aligned pangenome genes from panaroo output.

summarise\_pgfG.py and remove\_fG\_recombinations.py can be used together to generate gene alignments with recombinant bases identified by fastGEAR removed, and these can be combined into a concatenated core genome with concatenate\_core\_genome.py

Use --help to see help messages for individual script files.
